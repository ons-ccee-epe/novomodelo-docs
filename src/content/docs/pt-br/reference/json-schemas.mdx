Os arquivos de JSON Schema a seguir descrevem a estrutura de cada arquivo de entrada
JSON de um diretório de caso do Novo Modelo. Aponte a configuração de validação de JSON Schema
do seu editor para o arquivo apropriado para obter preenchimento automático, documentação ao passar o mouse
e destaque de erros em linha durante a elaboração das entradas do caso.

Para a descrição completa dos campos e das regras de validação de cada arquivo, ver
a página de referência [Formato do caso](/pt-br/reference/case-format/).

:::note[`operational_start_date`]
Todo esquema de cadastro de entidades `system/*` exige um campo `operational_start_date`;
[Formato do caso — Campos comuns das entidades](/pt-br/reference/case-format/#campos-comuns-as-entidades)
descreve seu formato e seu papel na ordem canônica das entidades.
:::

## Uso dos esquemas no editor

Todos os esquemas são servidos por este site em uma URL estável,
`/schemas/<name>.schema.json` (por exemplo,
`https://docs.modelossetoreletrico.org.br/schemas/config.schema.json`), que serve os
esquemas da versão do novomodelo descrita pela documentação mais recente. Cada versão
congelada da documentação, no seletor de versões do cabeçalho, serve os esquemas da sua
própria versão do novomodelo sob o seu caminho, `/vX.Y/schemas/<name>.schema.json`. Aponte
o mapeamento de JSON Schema do seu editor para a URL correspondente à versão do novomodelo que você
executa, para obter preenchimento automático e validação durante a elaboração das entradas do caso.

### VS Code

Acrescente uma entrada `json.schemas` ao arquivo `.vscode/settings.json` do seu workspace:

```json
{
  "json.schemas": [
    {
      "fileMatch": ["config.json"],
      "url": "https://docs.modelossetoreletrico.org.br/schemas/config.schema.json"
    },
    {
      "fileMatch": ["system/hydros.json"],
      "url": "https://docs.modelossetoreletrico.org.br/schemas/hydros.schema.json"
    }
  ]
}
```

Alternativamente, acrescente uma chave `$schema` diretamente em cada arquivo JSON:

```json
{
  "$schema": "https://docs.modelossetoreletrico.org.br/schemas/config.schema.json",
  "training": {
    "selection": { "method": "sampled", "forward_passes": 192 },
    "stopping_rules": [{ "type": "iteration_limit", "limit": 200 }]
  }
}
```

### Neovim (via `jsonls`)

Configure `json.schemas` na configuração do `nvim-lspconfig` para o `jsonls`,
seguindo o mesmo padrão de URL mostrado acima.

### IDEs JetBrains

Acesse **Preferences > Languages & Frameworks > Schemas and DTDs > JSON
Schema Mappings**, acrescente um novo mapeamento, cole a URL do esquema e selecione o
padrão de arquivos.

## Origem e atualização

Estes esquemas são gerados no repositório `novomodelo` a partir dos tipos Rust de `novomodelo-io`
— os tipos Rust são a fonte de verdade, e os arquivos de esquema são
sua saída gerada, licenciada sob Apache-2.0. Este site inclui a cópia
gerada no novomodelo `v0.20.0` em `public/schemas/`, para que os arquivos
tenham uma URL estável a partir da qual sejam servidos e referenciados.

Não edite manualmente nenhum arquivo de esquema incluído. Quando o `novomodelo` regenerar os
esquemas (após uma alteração em um tipo de entrada de `novomodelo-io`), atualize aqui a cópia
versionada com o comando abaixo (por padrão, ele lê a tag `v0.20.0`; `-- --ref <tag>`
seleciona outra):

```bash
npm run refresh:schemas
```

Execute `npm run refresh:schemas -- --check` para verificar se a cópia versionada ainda
corresponde à tag de origem, sem gravar nada.
